how to use this
1. power on the scooter, make sure no other app is connected to it.
2. on iphone: open in bluefy browser. on android: chrome works directly.
3. tap connect. pick the scooter (likely shows up as NB-... or similar).
4. expand each service to see characteristics. read grabs current value once. notify subscribes to live updates.
5. start riding and watch which characteristics emit data. that's your telemetry stream.
6. tap copy log to dump everything as text — paste it back to me and we'll decode it for v2.

note: if the scooter requires pairing/encryption, web bluetooth may show characteristics but reads/notifications fail. that tells us we need a different strategy. either way, this confirms what's possible.
