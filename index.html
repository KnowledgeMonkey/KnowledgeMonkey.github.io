      decoder context

      your function receives (bytes, ctx) where ctx has:

      • ctx.uuid — characteristic uuid the bytes came from

      • ctx.history — last 32 packets from this same characteristic

      • ctx.le16(off), ctx.be16(off), ctx.le32(off), ctx.be32(off), ctx.f32le(off), ctx.s16le(off) — byte readers

      

      return a string or object. objects render as key:value pairs. throw to mark as decode error.
